感兴趣的是分布式场景下那些"看起来简单、做起来到处是坑"的问题：缓存一致性、实时消息通道、数据该放在哪种存储里。近一年也在做 **AI 应用落地**，主要是 RAG 和 Agent 编排 —— 但我的态度是先把工程问题解决好，再谈模型能力。

## 我做过什么

**智慧工地安全智能监控平台**（团队项目 8 人，2026.08）
面向建筑工地的安全管理后端，包含设备台账、塔吊/升降机实时监控、AI 视频告警、喷淋联动。Spring Boot + MyBatis + MySQL。我负责监控大屏、告警处理和系统管理这几个模块，前后端都有。

**ServerOps 服务运维系统**（团队项目 8 人，2026.07 – 2026.08）
面向中小企业的服务器运维方案，指标采集、实时监控、告警闭环、自愈规则引擎。服务端 Java，采集端 Python，存储用 MySQL + InfluxDB 双库，知识库问答走 Milvus + DashScope Embedding，多 Agent 流程基于 Spring AI Alibaba。我主要写 WebSocket 推送和 AI 分析这条链路。

## 这个博客写什么

只写我自己项目里**真正踩过的坑**和做过的取舍，不写入门教程 —— 那些网上已经有很多，而且写得比我好。

我认为一篇技术笔记的价值在于：别人遇到同样问题时，能靠它少花两个小时。所以每篇尽量写清楚"现象 → 排查 → 原因 → 修法"，以及我最后为什么选了这个方案。
